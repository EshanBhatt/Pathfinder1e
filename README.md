# Pathfinder 1e — Dynamic Character Sheet

A single-file, no-build character sheet for Pathfinder 1st Edition.

- **Open it:** `index.html` works standalone in any browser, or via GitHub Pages once enabled (Settings → Pages → Deploy from branch → `main` / root).
- **Saving:** auto-detects storage — uses Claude's built-in storage when opened as a Claude artifact, otherwise falls back to your browser's local storage (per device/browser).
- **Import:** use the "Import from JSON file…" option on the character picker screen and select `eshan-druid.json` to load a pre-filled starting character.
- **Export:** use the "Export JSON" button any time to back up or move a character between devices.

Built with auto-calculating ability mods, skills, saves, AC, CMB/CMD, spell slots per day, and encumbrance, plus a bundled Core Rulebook feat/spell/skill reference you can search and drop straight onto the sheet.
